A [make.fun](https://make.fun) bounty entry: one Wi-Fi network name, written by a
pure-stdlib Python program.

## The name

> WiFi Went Out, So Did My Wife

29 characters. The Wi-Fi dropped — and so did the wife. A household, a
marriage, and the night the internet went down, told in one network name.

## How it works

`main.py` writes that single name (UTF-8, at most 32 characters, validated
in code) to `/output/entry.txt`. No dependencies, no network, deterministic:
every run produces the exact same bytes.

```sh
python3 main.py
```
